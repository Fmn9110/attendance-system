# Phase 3：前端开发汇总

> 日期：2026-09-19

## 一、已完成内容

- 首页 index.html：5 个班级大卡片
- 登录页 login.html：密码输入，回车提交
- 核心点名页 attendance.html：
  - 顶部固定状态栏（班级、日期、开始/当前时间、实时统计）
  - 搜索框（学号/姓名/电话）+ 状态筛选 chips
  - 学生卡片流（学号、姓名、电话、4 个状态按钮）
  - "其他"行内展开输入框 + 保存备注（无弹窗）
  - 底部固定导航（历史/花名册/导出）+ 结束按钮
  - 未完成学生时顶部横幅提示，可"继续点名"/"仍然结束"
  - 完成后原地展开完成卡片（耗时、统计、导出、下一次）
  - 乐观更新 + 离线暂存 + 网络恢复自动重试
- 导入页 import.html：文件上传 → 预览 → 确认导入
- 历史页 history.html：按日期范围查询，倒序列表
- 历史详情页 history_detail.html：单场完整学生名单 + 导出
- 导出页 export.html：按日期范围 / 多选场次导出
- 公共 api.js（Token、统一错误、401 自动跳登录）
- 公共 storage.js（离线队列、顶部红色提示条）
- base.css 移动端优先样式（大按钮、大字体、卡片）

## 四、如何运行

```bash
cd backend
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
# 手机/浏览器访问 http://<服务器IP>:8000
```
