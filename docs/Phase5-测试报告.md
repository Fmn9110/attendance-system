## 三、发现并修复的问题

**问题**：重新上传花名册后，历史 session 的学生列表只显示当前活跃学生，旧学生的点名状态丢失。

**修复**：`summarize` 和 `list_records` 对 `finished` 状态的 session 改为直接从 `attendance_records` 关联 `students` 表查询（不过滤 is_active），确保历史记录完整反映当时的学生名单。
